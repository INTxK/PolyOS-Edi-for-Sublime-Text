## PolyOS Editor v3.3.0 — auto-sync update

This release makes updates fully automatic. The package now ships as a single
bundle with:

- **Keybindings** (`F5` / `F6` / `F7`) and the prose / distraction-free plugins
  built in — no more manual `Packages/User` setup.
- **Shared preferences** shipped with the package, so your theme, color scheme
  and fonts follow every update.
- **Auto-sync plugin** — keeps per-device `Packages/User` settings
  (`Preferences (OSX|Windows).sublime-settings`, `Package Control.sublime-settings`)
  in sync across devices. It runs at startup, every 4 hours, or via
  `PolyOS: Sync Profile Now`.

No terminal or sync scripts needed anymore — just keep this package installed
and it updates itself when a new version is tagged.
