## PolyOS Editor v3.3.3 — self-healing Package Control baseline

- **The profile now re-asserts your Package Control baseline on every check.**
  Package Control wipes `installed_packages` during its startup bootstrap,
  which stopped upgrades from being tracked. The auto-sync plugin now restores
  the baseline (`Git`, `LSP`, `Transparency`, `PolyOS-Edi-for-Sublime-Text`,
  `Package Control` and the PolyOS repository) every time it runs — no more
  silently-untracked upgrades.
- The merge is a union and only writes when something actually changed, so it
  never disturbs unrelated Package Control state.

No theme or keybinding changes — just apply the upgrade.
