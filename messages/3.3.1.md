## PolyOS Editor v3.3.1 — use-ready on install

First-install polish: the profile now also applies the shared PolyOS
preferences into `Packages/User/` (theme, color scheme, default syntax,
font, caret and code-mode settings), so the PolyOS look turns on
immediately — even if Sublime was already carrying stock preferences
(`theme: auto`, Mariana scheme). The write is a merge: unrelated settings
you already had in `User/Preferences.sublime-settings` are kept.

Everything else is unchanged from v3.3.0: F5/F6/F7 keybindings, prose and
distraction-free plugins, and the auto-sync plugin that keeps your
`Packages/User` profile and Package Control baseline in sync across
devices.
