## PolyOS Editor v3.3.2 — fixes

- **Theme asset paths fixed.** The theme's textures (fold arrows, tabs,
  scrollbar, find bar, ...) were referenced with package-relative paths that
  Sublime resolves against `Packages/` — so they never loaded, producing
  "Unable to decode" errors and red UI glitches. All image references now use
  the full `Packages/PolyOS-Edi-for-Sublime-Text/assets/...` resource path.
- **Typewriter plugin removed.** `typewriter_center.py` never loaded on
  Sublime's Python 3.3 plugin host (f-string syntax) and has been dropped
  entirely. Prose-mode toggles (F5/F6/F7) are unaffected.

No profile or keybinding changes — just apply the upgrade.
